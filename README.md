# Wood & Grain Studio — Artisan Wood Carving Website

An artisan studio website for **Wood & Grain Studio**, celebrating hand-carved architectural panels, sculptural woodwork, and bespoke timber commissions.

## Pages Overview
- **Home 1 (`index.html`)**: Atelier showcase, artisan process, architectural reliefs, sustainable hardwood species guide, client reviews/reflections, and Back to Top.
- **Home 2 (`home2.html`)**: Modern Split Hero with artisan sculpture showcase, floating studio badge, studio hallmarks, equal-sized CTA buttons, single-line philosophy statement, and disciplines.
- **About (`about.html`)**: Workshop heritage, master carver team profiles, and workshop tenets.
- **Gallery (`gallery.html`)**: 12-piece wood carving portfolio with strictly equal card sizes, uniform grid alignment, and permanent institutional installations archive.
- **Products (`products.html`)**: Handcrafted wood carving catalog, filter pills, left-aligned commission actions, and reduced height imagery.
- **Custom (`custom.html`)**: 4-step commission journey, brief request form, and FAQ accordion.
- **Contact (`contact.html`)**: Single-line studio location, "Enquiry Form", interactive FAQ accordion, and centered social channels.
- **Login (`login.html`)**: Centered client portal card, "Remember me on this device", password eye toggle, Google/Apple/Facebook SVGs, and external theme/RTL toggles.
- **Signup (`signup.html`)**: Centered registration card, password eye toggles, Terms & Conditions checkbox, Google/Apple/Facebook SVGs, and external theme/RTL toggles.

## Features & Polish
- **Strictly Wood Carving Imagery**: Realistic high-resolution timber craftsmanship imagery across all pages.
- **Full Theme & RTL Support**: Seamless dark/light contrast and full right-to-left layout adaptation.
- **Mobile Navbar Refinement**: Header row displays only the brand and hamburger toggle. RTL toggle, Theme toggle, and Sign In button are housed inside the hamburger drawer.
- **Equal CTA Buttons**: Standardized 48px height and 210px width across all hero sections.
